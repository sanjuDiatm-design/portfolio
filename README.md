## ✨ Features

- 🌑 **Dark glassmorphism** design with animated background orbs
- 📱 **Fully responsive** — mobile, tablet, and desktop
- 🧭 **Smooth scroll navigation** with hamburger menu on mobile
- 💡 **Animated hero section** with floating skill chips and rotating avatar rings
- 🗂️ **Filterable project cards** by category (ML, NLP, Analytics)
- 📊 **Skills section** with animated proficiency bars and scrolling tool ticker
- 🎓 **Education timeline** with tabbed certifications panel
- 📬 **Contact form** with live submission feedback
- ⚡ **Micro-animations** throughout for a premium UX feel

## 🛠️ Getting Started

### Prerequisites

- **Node.js** ≥ 18
- **npm** ≥ 9

### Installation

```bash
# Clone the repository
git clone https://github.com/sanjuDiatm-design/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start local dev server with HMR |
| `npm run build` | Build optimized production bundle |
| `npm run preview` | Preview production build locally |
| `npm run lint` | Run Oxlint |

## 🌐 Deployment

This site is deployed on **Vercel** with automatic CI/CD — every push to `main` triggers a new deployment.

To deploy your own fork:

1. Fork this repo
2. Import it at [vercel.com/new](https://vercel.com/new)
3. Vercel auto-detects Vite — just click **Deploy**

## 🎨 Design System

The design uses a token-based system defined in [`src/index.css`](./src/index.css):

- **Primary palette**: Deep navy `#030712` backgrounds with purple `#a855f7`, blue `#60a5fa`, and cyan `#22d3ee` accents
- **Glassmorphism**: `backdrop-filter: blur()` with semi-transparent borders
- **Spacing scale**: `--space-xs` through `--space-4xl`
- **Responsive breakpoints**: `480px`, `600px`, `768px`, `900px`
